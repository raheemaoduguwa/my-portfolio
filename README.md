# Personal Engineering Portfolio

A responsive personal portfolio website showcasing my engineering background, technical skills, and featured hardware/software projects. Developed and managed using a professional Git and GitHub branching workflow.

## Live Deployment
View the live website here: [https://raheemaoduguwa.github.io/my-portfolio/](https://raheemaoduguwa.github.io/my-portfolio/)

## Technologies Used
- HTML5 (Semantic Layout)
- CSS3 (Flexbox, Grid, Responsive Design)
- Git & GitHub (Version Control, Feature Branching, Merge Workflows)
- GitHub Pages (Hosting & Deployment)

## Key Portfolio Sections
- **Home / Intro:** Professional title and engineering focus.
- **About Me:** Background in computer/electrical engineering, digital systems, and leadership.
- **Skills:** Hardware design, programming languages, and engineering tools.
- **Projects:** Technical breakdowns of embedded and software systems.
- **Contact:** Links to email and professional profiles.
